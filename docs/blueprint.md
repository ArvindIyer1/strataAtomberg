# **App Name**: Strata Performance

## Core Features:

- SMART Goal Engine: Create and manage professional goals with strict 100% total weightage validation and standardized unit measurements.
- AI Goal Refiner Tool: Utilizes generative AI as a professional tool to rewrite draft goals into SMART-compliant, performance-oriented descriptions.
- Role-Based Routing System: Dynamically shifts user views between Employee, Manager, and Admin portals based on session state without page reloads.
- Manager Review Workflow: Provides an interactive interface for managers to inline-edit, comment, and toggle between 'Approve' or 'Rework' states for team goals.
- Local Session Persistence: Implementation of local state management to simulate database behavior for goal storage and audit history using browser persistence.
- Real-time Progress Analytics: Data visualization dashboard featuring quarterly trends, achievement donuts, and team completion metrics using Recharts.
- HR Administrative Oversight: A control center for managing system-wide user states, goal unlocking, and exporting performance audit logs to CSV.

## Style Guidelines:

- Primary color: Enterprise Blue (#2563EB) to project stability and trust. Background: High-contrast cool white (#F8FAFC) for a spacious, modern feel. Accent: Sophisticated Teal-Cyan (#159DB1) for call-to-actions and interactive elements.
- A font pairing featuring 'Space Grotesk' for technical-feeling headlines and 'Inter' for highly legible, objective body text.
- Minimalist, thin-stroke Lucide icons used consistently across dashboards for navigational clarity and reduced cognitive load.
- A layout inspired by Linear/Stripe: collapsible sidebar, sticky headers, glassmorphism card surfaces (rounded-2xl), and deep z-index shadow depth for information hierarchy.
- Soft layout transitions and micro-interactions using Framer Motion to ensure the interface feels snappy and responsive rather than static.
